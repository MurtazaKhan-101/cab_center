ok so this backend is going to be for a Booking, Drivers and Cars management system for a Cab Center Admin

The required db models are Booking, Driver, Vehicle

Booking Fields are going to be the following:
1. user_id (from User model)
2. user_name (to be supplied by user during booking)
3. contact_number (to supplied by user during booking)
4. email (to be supplied by user during booking)
5. no_of_passengers (to be supplied by user during booking)
6. special_requirements (optional, to be supplied by user during booking)
7. pickup (to be supplied by user during booking)
8. drop (to be supplied by user during booking)
9. vehicle_type (to be supplied by user during booking)
10. vehicle_id (to be set by admin when booking request is received)
11. driver (to be set by admin when booking request is received)
12. total_fair (going to be calculated based on selected vehicle type's fair/km and rush hours(specified by admin))
13. Date (to be supplied by user during booking)
14. Time (to be supplied by user during booking)

Driver Fields are going to be the following:
1. id

6. assigned_vehicle_id (from Vehicle table)

Vehicle Fields are going to be the following:
